## 확인된 사실 (글에 써도 되는 것)
- SwiftReceipt: 결제 영수증 웹앱. 완납·선금·일부 결제·환불 4종, 남은 금액 자동 계산, 화폐 7개(USD·EUR·GBP·CAD·AUD·KRW·JPY), 미국/영국/유럽 표기, A4·US Letter, 가입 없음, 데이터는 브라우저에만 저장
- 무료: 한 달 PDF 3장(작은 "free version" 표시), SwiftBill 인보이스 가져오기
- Pro 9달러 한 번 결제: PDF 무제한·표시 없음, 디자인 3종, 로고·서명, 영수증 저장(20개)·복제·백업, 브라우저 3개, 7일 환불

- 만든 사람: 한국의 1인 개발자

## 4. 인디해커스 (Indie Hackers) — 만든 과정 공유 글
**제목**
```
Turning one $9 tool into two + a $14 bundle without a backend
```
**본문**
```
A few days ago I launched SwiftBill, a browser-only invoice maker for freelancers ($9 one-time Pro). Now I've added SwiftReceipt, a payment receipt maker, and a bundle.

A few things that were fun to figure out:
- Both apps live on the same GitHub Pages site, so they can share browser storage. SwiftReceipt can import an invoice from SwiftBill without any server.
- One Gumroad bundle key unlocks both apps: whichever app sees the key first shares it with the other, and the browser is only counted once toward the 3-device limit.
- No backend at all, so I'm honest in the docs that someone who edits the page code can bypass Pro. The target is people who'd rather pay $9 than fiddle.

Pricing: free tier (3 PDFs/month with a small credit), Pro $9 each, both for $14.
Sales so far: just launched, so nothing to brag about yet — I'll post numbers either way.

Would love feedback on the pricing and on what you'd want in a receipt.
```
